Node.js and TypeScript BFF

Owned by the frontend team
  • Aggregates calls across services

  • Centralizes JWT, OAuth and Keycloak auth

Pick the rendering strategy per screen

Live dashboards suit client rendering. Marketing pages need SSR or ISR. My Next.js dashboard proof of concept improved Time-to-Interactive by about 35%.

Keep clients thin

Moving aggregation and auth into a BFF cut client-side data fetching and made real-time device status updates more reliable.

Measure before and after

Bundle size, Core Web Vitals and render time guide each change, which is how IP Maestro gained 30% in performance.
